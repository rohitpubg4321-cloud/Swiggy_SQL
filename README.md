                                   # 🍽️ Swiggy SQL Data Analysis

## 📌 Project Overview

This project focuses on analyzing a Swiggy food delivery dataset using SQL. It demonstrates SQL techniques ranging from intermediate to advanced concepts, along with business insight-driven analysis. The project is designed to strengthen SQL problem-solving skills and showcase practical data analysis techniques used in real-world scenarios.

---

## 📂 Dataset

The project uses a single Swiggy dataset containing the following information:

- State
- City
- Order Date
- Restaurant Name
- Location
- Category
- Dish Name
- Price (INR)
- Rating
- Rating Count

---

## 📚 Query Levels

### 🟢 Intermediate SQL
Queries that focus on data exploration, filtering, grouping, aggregation, and basic analytical techniques.

### 🔵 Advanced SQL
Queries using CTEs, Window Functions, Subqueries, Ranking Functions, and complex SQL logic to solve analytical problems.

### 🟣 Business Insight Queries
SQL analysis designed to extract meaningful business insights from the dataset, helping identify trends, performance metrics, and decision-making opportunities.
